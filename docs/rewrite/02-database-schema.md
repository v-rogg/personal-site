# Database Schema

## Overview

Single SQLite database with WAL mode for concurrent reads during writes.

```
┌─────────────┐
│   users     │
└──────┬──────┘
       │ 1:n
       ▼
┌─────────────┐
│  sessions   │
└──────┬──────┘
       │ 1:n
       ▼
┌─────────────┬─────────────┬─────────────┐
│   events    │ signatures  │ page_views  │
└─────────────┴─────────────┴─────────────┘
```

---

## Tables

### users

Created when a user performs an identifying action (signature creation, contact form submission).

```sql
CREATE TABLE users (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    email TEXT,
    ts_created INTEGER NOT NULL,
    
    CONSTRAINT email_unique UNIQUE(email)
);

CREATE INDEX idx_users_email ON users(email);
```

| Column | Type | Nullable | Description |
|--------|------|----------|-------------|
| id | INTEGER | No | Auto-incrementing primary key |
| email | TEXT | Yes | Email address (unique if provided) |
| ts_created | INTEGER | No | Unix timestamp of creation |

**Notes:**
- Email is optional (signature without email)
- Email has unique constraint to prevent duplicates
- If user submits contact form with same email, existing user is reused

---

### sessions

Created on first event from a session. Linked to user on identifying action.

```sql
CREATE TABLE sessions (
    id TEXT PRIMARY KEY,
    user_id INTEGER,
    country_code TEXT,
    region TEXT,
    ts_created INTEGER NOT NULL,
    ts_last_seen INTEGER NOT NULL,
    
    FOREIGN KEY (user_id) REFERENCES users(id)
);

CREATE INDEX idx_sessions_user ON sessions(user_id);
CREATE INDEX idx_sessions_last_seen ON sessions(ts_last_seen);
CREATE INDEX idx_sessions_country ON sessions(country_code);
```

| Column | Type | Nullable | Description |
|--------|------|----------|-------------|
| id | TEXT | No | UUID generated by frontend (in-memory) |
| user_id | INTEGER | Yes | FK to users, NULL until identified |
| country_code | TEXT | Yes | ISO 3166-1 alpha-2 (e.g., "DE", "US") |
| region | TEXT | Yes | Region/state (e.g., "Bavaria", "California") |
| ts_created | INTEGER | No | Unix timestamp of first event |
| ts_last_seen | INTEGER | No | Unix timestamp of last event |

**Notes:**
- `id` is a UUIDv4 generated client-side, held in memory only
- `user_id` remains NULL for anonymous sessions
- `ts_last_seen` updated on every event
- `country_code` and `region` derived from IP via GeoIP lookup (server-side)

---

### signatures

Stores signature drawings, linked to the session that created them.

```sql
CREATE TABLE signatures (
    id TEXT PRIMARY KEY,
    session_id TEXT NOT NULL,
    name TEXT NOT NULL,
    signature TEXT NOT NULL,
    approved INTEGER NOT NULL DEFAULT 0,
    ts_created INTEGER NOT NULL,
    ts_modified INTEGER,
    
    FOREIGN KEY (session_id) REFERENCES sessions(id)
);

CREATE INDEX idx_signatures_session ON signatures(session_id);
CREATE INDEX idx_signatures_approved ON signatures(approved);
CREATE INDEX idx_signatures_created ON signatures(ts_created);
```

| Column | Type | Nullable | Description |
|--------|------|----------|-------------|
| id | TEXT | No | Petname like "happy-blue-cat" |
| session_id | TEXT | No | FK to sessions |
| name | TEXT | No | Display name entered by user |
| signature | TEXT | No | Base64 + gzip compressed drawing data |
| approved | INTEGER | No | 0 = pending, 1 = approved |
| ts_created | INTEGER | No | Unix timestamp of creation |
| ts_modified | INTEGER | Yes | Unix timestamp of last modification |

**Notes:**
- `id` generated using petname format (adjective-noun-noun)
- `signature` is base64-encoded, gzip-compressed drawing data
- Only approved signatures shown in carousel

---

### events

Stores all trackable user events.

```sql
CREATE TABLE events (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    session_id TEXT NOT NULL,
    event_name TEXT NOT NULL,
    timestamp INTEGER NOT NULL,
    properties TEXT,
    
    FOREIGN KEY (session_id) REFERENCES sessions(id)
);

CREATE INDEX idx_events_session ON events(session_id);
CREATE INDEX idx_events_name ON events(event_name);
CREATE INDEX idx_events_timestamp ON events(timestamp);
CREATE INDEX idx_events_name_ts ON events(event_name, timestamp);
```

| Column | Type | Nullable | Description |
|--------|------|----------|-------------|
| id | INTEGER | No | Auto-incrementing primary key |
| session_id | TEXT | No | FK to sessions |
| event_name | TEXT | No | Event identifier |
| timestamp | INTEGER | No | Unix timestamp of event |
| properties | TEXT | Yes | JSON object with event-specific data |

---

### page_views

Tracks individual page visits with engagement metrics.

```sql
CREATE TABLE page_views (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    session_id TEXT NOT NULL,
    path TEXT NOT NULL,
    referrer TEXT,
    ts_start INTEGER NOT NULL,
    ts_end INTEGER,
    duration_seconds INTEGER,
    max_scroll_percent INTEGER DEFAULT 0,
    
    FOREIGN KEY (session_id) REFERENCES sessions(id)
);

CREATE INDEX idx_page_views_session ON page_views(session_id);
CREATE INDEX idx_page_views_path ON page_views(path);
CREATE INDEX idx_page_views_start ON page_views(ts_start);
```

| Column | Type | Nullable | Description |
|--------|------|----------|-------------|
| id | INTEGER | No | Auto-incrementing primary key |
| session_id | TEXT | No | FK to sessions |
| path | TEXT | No | Page path (e.g., "/", "/blog/post-1") |
| referrer | TEXT | Yes | Referrer URL (external only) |
| ts_start | INTEGER | No | Unix timestamp when page was opened |
| ts_end | INTEGER | Yes | Unix timestamp when user left page |
| duration_seconds | INTEGER | Yes | Calculated: ts_end - ts_start |
| max_scroll_percent | INTEGER | No | Maximum scroll depth (0-100) |

**Notes:**
- `ts_end` and `duration_seconds` updated via beacon/heartbeat on page unload
- `max_scroll_percent` updated as user scrolls (only tracks maximum)
- `referrer` only stores external referrers, not internal navigation

## Event Types

Events table is for discrete actions. Page views have their own table for richer tracking.

### Signature Events

| Event Name | Properties | Description |
|------------|------------|-------------|
| `editor.open` | `{}` | User opened signature editor |
| `editor.eraser` | `{}` | User clicked eraser tool |
| `editor.save` | `{}` | User saved signature |

### Form Events

| Event Name | Properties | Description |
|------------|------------|-------------|
| `contact.submit` | `{}` | Contact form submitted |
| `signature.submit` | `{ "signature_id": "..." }` | Signature created |

### Interaction Events (Optional)

| Event Name | Properties | Description |
|------------|------------|-------------|
| `click` | `{ "target": "#id", "text": "..." }` | Click on interactive element |
| `outbound_link` | `{ "url": "..." }` | Click on external link |

## Common Queries

### Get all approved signatures (for carousel)

```sql
SELECT id, name, signature, ts_created
FROM signatures
WHERE approved = 1
ORDER BY ts_created DESC;
```

### Get single signature with user info

```sql
SELECT 
    sig.id,
    sig.name,
    sig.signature,
    sig.ts_created,
    u.email
FROM signatures sig
JOIN sessions s ON sig.session_id = s.id
LEFT JOIN users u ON s.user_id = u.id
WHERE sig.id = ?;
```

### Get user journey (all events + signatures)

```sql
SELECT 
    e.event_name,
    e.timestamp,
    e.properties,
    sig.id as signature_id
FROM sessions s
LEFT JOIN events e ON s.id = e.session_id
LEFT JOIN signatures sig ON s.id = sig.session_id
WHERE s.user_id = ?
ORDER BY e.timestamp;
```

### Conversion rate (sessions that opened editor vs saved)

```sql
SELECT 
    COUNT(DISTINCT CASE WHEN event_name = 'editor.open' THEN session_id END) as opened,
    COUNT(DISTINCT CASE WHEN event_name = 'editor.save' THEN session_id END) as saved,
    ROUND(
        COUNT(DISTINCT CASE WHEN event_name = 'editor.save' THEN session_id END) * 100.0 /
        NULLIF(COUNT(DISTINCT CASE WHEN event_name = 'editor.open' THEN session_id END), 0),
        2
    ) as conversion_rate
FROM events
WHERE timestamp > unixepoch() - (86400 * ?);  -- ? = days
```

### Average drawing time

```sql
SELECT AVG(duration) as avg_seconds
FROM (
    SELECT 
        e_open.session_id,
        MIN(e_save.timestamp - e_open.timestamp) as duration
    FROM events e_open
    JOIN events e_save ON e_open.session_id = e_save.session_id
    WHERE e_open.event_name = 'editor.open'
      AND e_save.event_name = 'editor.save'
      AND e_save.timestamp > e_open.timestamp
    GROUP BY e_open.session_id
);
```

### Drawing durations with signature IDs

```sql
SELECT 
    sig.id as signature_id,
    MIN(e_save.timestamp - e_open.timestamp) as duration_seconds,
    sig.ts_created
FROM signatures sig
JOIN events e_open ON sig.session_id = e_open.session_id AND e_open.event_name = 'editor.open'
JOIN events e_save ON sig.session_id = e_save.session_id AND e_save.event_name = 'editor.save'
WHERE e_save.timestamp > e_open.timestamp
GROUP BY sig.id
ORDER BY duration_seconds DESC;
```

### Average eraser uses per session

```sql
SELECT AVG(eraser_count) as avg_eraser_uses
FROM (
    SELECT session_id, COUNT(*) as eraser_count
    FROM events
    WHERE event_name = 'editor.eraser'
      AND timestamp > unixepoch() - (86400 * ?)
    GROUP BY session_id
);
```

### Link session to user (on identifying action)

```sql
-- Create user
INSERT INTO users (email, ts_created) VALUES (?, unixepoch())
ON CONFLICT(email) DO UPDATE SET email = email
RETURNING id;

-- Link session to user
UPDATE sessions SET user_id = ? WHERE id = ?;
```

## Analytics Queries

### Page views by path (last N days)

```sql
SELECT 
    path,
    COUNT(*) as views,
    COUNT(DISTINCT session_id) as unique_visitors,
    AVG(duration_seconds) as avg_duration_seconds,
    AVG(max_scroll_percent) as avg_scroll_percent
FROM page_views
WHERE ts_start > unixepoch() - (86400 * ?)
GROUP BY path
ORDER BY views DESC;
```

### Average time on site per session

```sql
SELECT AVG(session_duration) as avg_session_seconds
FROM (
    SELECT 
        session_id,
        SUM(duration_seconds) as session_duration
    FROM page_views
    WHERE ts_start > unixepoch() - (86400 * ?)
      AND duration_seconds IS NOT NULL
    GROUP BY session_id
);
```

### Scroll depth distribution

```sql
SELECT 
    CASE 
        WHEN max_scroll_percent < 25 THEN '0-24%'
        WHEN max_scroll_percent < 50 THEN '25-49%'
        WHEN max_scroll_percent < 75 THEN '50-74%'
        WHEN max_scroll_percent < 100 THEN '75-99%'
        ELSE '100%'
    END as scroll_bucket,
    COUNT(*) as count,
    ROUND(COUNT(*) * 100.0 / SUM(COUNT(*)) OVER (), 1) as percentage
FROM page_views
WHERE ts_start > unixepoch() - (86400 * ?)
GROUP BY scroll_bucket
ORDER BY scroll_bucket;
```

### Visitors by country

```sql
SELECT 
    country_code,
    COUNT(DISTINCT id) as sessions,
    COUNT(DISTINCT user_id) as identified_users
FROM sessions
WHERE ts_created > unixepoch() - (86400 * ?)
  AND country_code IS NOT NULL
GROUP BY country_code
ORDER BY sessions DESC
LIMIT 20;
```

### Visitors by region (for a specific country)

```sql
SELECT 
    region,
    COUNT(DISTINCT id) as sessions
FROM sessions
WHERE ts_created > unixepoch() - (86400 * ?)
  AND country_code = ?
  AND region IS NOT NULL
GROUP BY region
ORDER BY sessions DESC;
```

### Top referrers

```sql
SELECT 
    referrer,
    COUNT(*) as visits,
    COUNT(DISTINCT session_id) as unique_sessions
FROM page_views
WHERE ts_start > unixepoch() - (86400 * ?)
  AND referrer IS NOT NULL
  AND referrer != ''
GROUP BY referrer
ORDER BY visits DESC
LIMIT 20;
```

### Bounce rate (single page sessions)

```sql
SELECT 
    ROUND(
        COUNT(DISTINCT CASE WHEN page_count = 1 THEN session_id END) * 100.0 /
        NULLIF(COUNT(DISTINCT session_id), 0),
        1
    ) as bounce_rate_percent
FROM (
    SELECT session_id, COUNT(*) as page_count
    FROM page_views
    WHERE ts_start > unixepoch() - (86400 * ?)
    GROUP BY session_id
);
```

### Engagement funnel (home → signature editor → signature saved)

```sql
SELECT 
    COUNT(DISTINCT pv.session_id) as visited_home,
    COUNT(DISTINCT CASE WHEN e_open.session_id IS NOT NULL THEN pv.session_id END) as opened_editor,
    COUNT(DISTINCT CASE WHEN e_save.session_id IS NOT NULL THEN pv.session_id END) as saved_signature
FROM page_views pv
LEFT JOIN events e_open ON pv.session_id = e_open.session_id AND e_open.event_name = 'editor.open'
LEFT JOIN events e_save ON pv.session_id = e_save.session_id AND e_save.event_name = 'editor.save'
WHERE pv.path = '/'
  AND pv.ts_start > unixepoch() - (86400 * ?);
```

### Daily active sessions

```sql
SELECT 
    date(ts_created, 'unixepoch') as day,
    COUNT(DISTINCT id) as sessions,
    COUNT(DISTINCT user_id) as identified_users
FROM sessions
WHERE ts_created > unixepoch() - (86400 * ?)
GROUP BY day
ORDER BY day DESC;
```

## Data Migration (from D1)

Export existing signatures from D1:

```sql
-- Run against D1
SELECT id, name, signature, approved, ts_created, ts_modified
FROM signatures;
```

Import into new SQLite (will need to create placeholder sessions):

```sql
-- For each migrated signature, create an anonymous session
INSERT INTO sessions (id, user_id, ts_created, ts_last_seen)
VALUES ('migrated-' || ?, NULL, ?, ?);

INSERT INTO signatures (id, session_id, name, signature, approved, ts_created, ts_modified)
VALUES (?, 'migrated-' || ?, ?, ?, ?, ?, ?);
```

## Backup Strategy

Simple file-based backup (no object storage):

```bash
#!/bin/bash
# /etc/cron.daily/backup-sqlite

DB_PATH="/data/app.db"
BACKUP_DIR="/backups"
DATE=$(date +%Y%m%d_%H%M%S)

# Use SQLite backup command for consistency
sqlite3 "$DB_PATH" ".backup '$BACKUP_DIR/app_$DATE.db'"

# Keep last 7 days
find "$BACKUP_DIR" -name "app_*.db" -mtime +7 -delete
```

For WAL mode, ensure checkpoint before backup:

```bash
sqlite3 "$DB_PATH" "PRAGMA wal_checkpoint(TRUNCATE);"
sqlite3 "$DB_PATH" ".backup '$BACKUP_DIR/app_$DATE.db'"
```
